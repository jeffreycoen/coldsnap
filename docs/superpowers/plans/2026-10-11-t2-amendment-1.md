# T2 — Amendment 1: the stamp count in the T1 era

T2's dispatch stopped at the `depot-test` gate with one failure outside the new era: `scripts/tests/48-the-outbreak.mjs` (k), "the sickness stamp rides the save". That assert boots an outbreak, ticks two seconds, stamps one enemy man, saves, resumes, and expects exactly one stamped body on the resumed field. It assumed nobody is bitten in the first two seconds. With T2 the middle town's people stand at their doors inside the outbreak ring, and one of them is bitten in that time, so the resumed field carries two stamps. The code does what the design says; the test pinned a fixture condition the people break. This amendment re-teaches that one assert: count the stamped bodies before the save and require the resumed count to equal it. The asserted content is unchanged — the stamp rides the save.

The tree holds T2's Steps 1–15 applied and uncommitted. This amendment inserts one step before Step 16; the plan's other steps, gates, and numbers stand, with one total corrected below.

## Step 15a — the re-teach

In `scripts/tests/48-the-outbreak.mjs`, replace lines 124–125

```js
    const m = ob.world.bodies.find((b) => b.kind === "unit" && b.team === 2 && b.alive); if (m) m.sickAt = ob.world.t;
    const n0 = ob.world.bodies.filter((b) => b.kind === "unit" && b.team === DEAD_TEAM && b.alive).length;
```

with

```js
    const m = ob.world.bodies.find((b) => b.kind === "unit" && b.team === 2 && b.alive); if (m) m.sickAt = ob.world.t;
    const n0 = ob.world.bodies.filter((b) => b.kind === "unit" && b.team === DEAD_TEAM && b.alive).length;
    const sick0 = ob.world.bodies.filter((b) => b.sickAt != null).length; // 0.6.2: the people stand inside the ring and may be bitten by now — count what is stamped, then expect it back
```

and replace lines 131–132

```js
    const sick = back.world.bodies.filter((b) => b.sickAt != null).length;
    ok("(k) the sickness stamp rides the save", !m || sick === 1, `${sick}`);
```

with

```js
    const sick = back.world.bodies.filter((b) => b.sickAt != null).length;
    ok("(k) the sickness stamp rides the save", sick === sick0 && sick0 >= 1, `${sick0}->${sick}`);
```

The assert still requires at least one stamp (the one the test writes) and that every stamp comes back; it no longer requires that nobody else was bitten.
