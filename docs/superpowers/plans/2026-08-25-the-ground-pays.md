# THE GROUND PAYS — phase document (2026-08-25)

Owner's scope ruling, 2026-08-25: this phase ships the ground-scaled income and the building flags, nothing else. New building types, the doubled building count, and troops entering buildings stay in design.

## Rulings this phase is built on (owner, 2026-08-25)

1. Income is the clock, scaled by held ground: 1 scrap/second for the starting area, continuously more for more ground held (fractions included).
2. The rate never falls under 1/second — the floor.
3. One pay law, one per-second schedule, both sides. The enemy's 90-per-bell stipend dies.
4. Building pay (4 per standing held building per bell) stays on top.
5. Standing buildings fly a holder-colored flag; neutral or contested ground flies none; a ruined building flies none and pays nothing (already the law).
6. Flags are render-only — never bodies, never eyes, never territory emitters.
