## The design, plainly

**The walk (explode).** The burst walked `world.bodies` twice: once to pick the occluders (the bodies that can cast a shadow: not a man, alive or a wreck, at least a quarter meter across, within `spec.r + 8` of the burst on the ground), and once more over every body as a target, skipping each whose distance is past its reach. Now one walk does both. A body goes on the target list when its ground distance alone is not past its reach (`Math.sqrt(dox * dox + doz * doz) > spec.r + ext`, the loop's own `reach`): a body whose ground distance is past its reach has a true distance past it too, so the loop skipped it before it did anything; the loop keeps its full test on the list it is given, in body order, so every wake, every push, every joint shock and every random draw lands on the same body in the same order. The occluder rule is unchanged, and the disc is the old one — `spec.r + 8` covers every body any center-to-target segment can touch (target reach plus both extents).

**The shadow grid.** The occluders are filed on a grid of two-meter cells over the ground, each body in every cell its bounding circle touches, the circle padded by half a meter: 0.26 for the test's fattening of every box by 0.15 on three axes, 0.22 for the two lateral rays, which run beside the center ray at that offset. A target's test walks the cells the center ray's ground track crosses (the track is cut column by column, or row by row when it runs more north-south than east-west; each cut's span is widened by a millionth so no rounding at a cell line can skip the cell a point lies in) and collects the bodies filed there, each once. Any body one of the three rays hits is within the padded circle of a point on the center ray, so it is filed in a cell the track crosses: the candidates are a superset of the hits. The old test multiplied the shadow by 0.35 per hit and stopped at the third; that result depends only on the number of hits, not the order they were found in, so counting hits over the candidates (stopping at three) and then multiplying the same way, in the same order, gives the same number to the bit. The chord test against the ground is unchanged and runs after the count as before. On the fresh copy a ray in the town met 40 to 120 candidates instead of the disc's ~500.

**The aloft watch.** A davy round is in the air for seconds. While it flies, the engine (at the end of each step, `stepAloft`) takes every still body — asleep or massless; never a man, never a mech's link, since the game moves those by hand — as frozen: their list, a set, a shadow grid of the whole ground, and each one's alive flag, read off a copy of the body list six hundred bodies a step, so the taking costs about a millisecond a step for ten steps instead of a hitch. The set is live from the first step, so a filed body that wakes before the filing is done counts against the watch like any later wake. Then it flies a ghost of the round ahead, sixty steps a step, with the round's own arithmetic (`stepProjectiles`: gravity, the wind's drag, the ground's bisection, the first box hit) against the frozen bodies alone, reading the wind for each future step from the game layer (`world._windAt`, the war's own wind function, and `world._windOn`, the toggle) exactly as the game layer will set it. When the ghost lands it holds the burst point; from then on, eight frozen targets a step get their three rays counted against the frozen grid and their chord flags read, packed into one small number each. At the burst, the counts serve only if the burst point equals the ghost's to the bit (the same round, by its spec object), no frozen body woke since the watch was taken (a counter in `wake` and at the partner wake, over the set), none died or left (the alive flags and `world.byId` checked over the list), and the ground was not carved (`field.edits`, counted by every carve and by the game's own rock breach). Then a frozen target's shadow is its precount plus the hits among the live bodies — those not in the frozen set, filed on their own small grid at the burst — and an unfrozen target, or one the precount did not reach, is tested against both grids; the disc's filter on the frozen bodies (alive, size, distance) is read once at the burst's start, as the old walk read its list, so a tree the burst's own loop kills still shades the targets after it. If any condition fails, the watch is dropped and the burst tests everything itself, as a round that was never watched does. The watch writes nothing but its own record on the world, draws nothing, and moves nothing; a step with no davy aloft pays one look at the projectile list. Measured on the fresh copy against the same flight with no watch: the filing steps cost about 1 ms more each, the ghost's eight steps about 1 ms more each, the counting steps nothing the noise shows. Only a davy round is watched (its spec names the weapon and tests structures); every other round takes the plain grid path.

**The road map, once a tick.** The map the enemy follows (`computeFlowField`) was redrawn inside every structure loss, every ruined building, and every rock breach — ten or fifty times in the burst's tick. Now every such call raises a flag, and one redraw runs at the start of the next tick, just before the enemy reads the map (`stepEnemies`, the first thing `stepDepot` does). The map's only readers are the enemy's drivers and marchers in that call; every raise happens after it in the tick (the losses after `stepWorld`, the ruins in `stepTown`, the breach in `drainEvents`, the build line inside the squads' loop, the player's placements between ticks); and nothing changes the grid's blocked cells between the last raise and the redraw. So every reader sees the map the separate redraws would have given it, and the redraw runs once per tick that lost something instead of once per thing lost.

**What is identical.** Every body's position, velocity, pose, flags and clocks, every joint's force and break, every event, every random draw, and every read of the road map. The new test proves the shadow to the bit over every target of a burst, the precount against a count by hand, the ghost's burst point against the real one, a twin world with its watch dropped against one whose watch served (the same hash and draw count four seconds after the burst), and an occluder killed during the burst's loop still shading the targets after it, served or not; `golden` proves the demo's world, the keystone the war's, the bench's identity check T9's seed over 25 seconds with a bang in three worlds plus the lofted round in two.

The projectile's own hit test (every body, every step, every round: 2–3 ms a step while a round flies, in the base too) is noted for the queue, not folded in.

// fireDavyUp(world, field, x, z, s): the same round from the same muzzle,
// fired straight up at the speed that brings it back to the muzzle s seconds
// later (v = g s / 2; the engine's own wind drag drifts it a little), so the
// round is aloft long enough for the aloft watch (0.6.11) to do its work
// before the burst. Returns the muzzle height.
export function fireDavyUp(world, field, x, z, s) {
  let top = field.heightAt(x, z);
  for (const b of world.bodies) {
    if (!b.alive) continue;
    const dx = b.pos.x - x, dz = b.pos.z - z;
    if (dx * dx + dz * dz > 4) continue;
    const t = b.pos.y + b.hy;
    if (t > top) top = t;
  }
  const y = top + 1;
  fireProjectile(world, { x, y, z }, { x: 0, y: 1, z: 0 }, world.gravity * s / 2, {
    kind: DAVY_FIRE.kind, r: DAVY_FIRE.blastR, kv: DAVY_FIRE.kv, dmg: DAVY_FIRE.dmg, crater: DAVY_FIRE.crater,
    weapon: DAVY_FIRE.weapon, noImpact: true, attacker: "enemy", windF: DAVY_FIRE.windF, hitStruct: true,
  });
  return y;
}

// ------------------------------------------------------------ the shadow grid
// 0.6.11: THE BANG. A burst's shadow test (explode's occOf) walked every
// occluder in the disc for every target, three rays each. Now the occluders
// are filed on a grid of two-meter cells over the ground, each body in every
// cell its padded bounding circle touches, and a ray's test walks only the
// cells its ground track crosses. The pad (0.26 for the test's 0.15 m box
// fattening on three axes, 0.22 for the lateral rays' offset from the center
// ray, whose track is the one walked) makes the cells' bodies a superset of
// the three rays' hits; a shadow is a count of hits capped at three, blind to
// the order they are found in; so the result is the full scan's to the bit.
const SH_CELL = 2, SH_PAD = 0.5;
const shKey = (gx, gz) => (gx + 32768) * 65536 + (gz + 32768);
function shadowFile(grid, b, i) {
  const r = Math.sqrt(b.hx * b.hx + b.hy * b.hy + b.hz * b.hz) + SH_PAD;
  const x0 = Math.floor((b.pos.x - r) / SH_CELL), x1 = Math.floor((b.pos.x + r) / SH_CELL);
  const z0 = Math.floor((b.pos.z - r) / SH_CELL), z1 = Math.floor((b.pos.z + r) / SH_CELL);
  for (let gx = x0; gx <= x1; gx++) for (let gz = z0; gz <= z1; gz++) {
    const k = shKey(gx, gz), c = grid.get(k);
    if (c) c.push(i); else grid.set(k, [i]);
  }
}
// the bodies filed in the cells a ground track crosses, each once (stamped),
// appended to out. The track is cut column by column (row by row when it
// runs more north-south than east-west); each cut's span is widened by a
// hair so no rounding at a cell line can skip the cell a point lies in.
function shadowAlong(grid, stamp, s, ax, az, bx, bz, out) {
  const cs = SH_CELL, eps = 1e-6;
  const byX = Math.abs(bx - ax) >= Math.abs(bz - az);
  const a0 = byX ? ax : az, b0 = byX ? bx : bz, a1 = byX ? az : ax, b1 = byX ? bz : bx;

  const g0 = Math.floor((lo - eps) / cs), g1 = Math.floor((hi + eps) / cs);
  for (let g = g0; g <= g1; g++) {
    const pl = Math.max(g * cs, lo), ph = Math.min((g + 1) * cs, hi);
    let ql, qh;

const occluderInDisc = (o, x, z, oR) => {
  if (!o.alive && o.kind !== "wreck") return false;
  if (Math.max(o.hx, o.hy, o.hz) < 0.25) return false;
  const dox = o.pos.x - x, doz = o.pos.z - z;
  return !(dox * dox + doz * doz > oR * oR);

// the shadow state of one burst: the targets in reach in body order, the live
// occluders filed on their own grid, and the watched round's frozen grid and
// precounted hits when this is its burst and nothing frozen has changed
function shadowState(world, x, y, z, spec) {
  const oR = spec.r + 8;
  const ep = aloftEpochFor(world, spec, x, y, z);
  const frozen = ep !== null ? ep.set : null, nF = ep !== null ? ep.list.length : 0;
  const targets = [], live = [], liveGrid = new Map();
  for (const o of world.bodies) {
    const dox = o.pos.x - x, doz = o.pos.z - z, d2 = dox * dox + doz * doz;
    const ext = Math.max(o.hx, o.hy, o.hz);
    // a target: explode's loop keeps its full test; a body whose ground
    // distance alone is past its reach is one that test skips
    if (o.invM !== 0 && (o.alive || o.kind !== "unit") && !(Math.sqrt(d2) > spec.r + ext)) targets.push(o);
    if (o.kind === "unit") continue;
    if (!o.alive && o.kind !== "wreck") continue;
    if (ext < 0.25) continue;
    if (d2 > oR * oR) continue;
    if (frozen !== null && frozen.has(o)) continue; // on the watch's grid already
    shadowFile(liveGrid, o, nF + live.length);
    live.push(o);
  }
  // the disc's filter on the frozen bodies, read once here as the old walk
  // read it: a tree the loop kills still shades the targets after it
  let fz = null;
  if (ep !== null) { fz = new Uint8Array(nF); for (let i = 0; i < nF; i++) fz[i] = occluderInDisc(ep.list[i], x, z, oR) ? 1 : 0; }
  return { c: v3(x, y, z), x, y, z, oR, ep, nF, fz, targets, live, liveGrid, stamp: new Uint32Array(nF + live.length), s: 0 };
}
// the shadow on one target: the three-ray test over the bodies the grids
// list along the center ray's track; the frozen bodies' hits come from the
// watch when it counted them aloft
function shadowOf(world, S, b, dist) {
  if (dist < 1.1) return 1; // point-blank: you are the surface
  const x = S.x, y = S.y, z = S.z, ep = S.ep;
  // three rays (center and two lateral offsets), averaged: a mortar seam between two
  // stones shouldn't fry the man behind the wall, and a sliver shouldn't blank a blast.
  const px = -(b.pos.z - z), pz = (b.pos.x - x);
  const pl = Math.hypot(px, pz) || 1;
  const off = 0.22 * Math.min(1, dist / 2);
  const pre = ep !== null ? ep.hits.get(b) : undefined;
  const cand = _shCand; cand.length = 0; S.s++;
  shadowAlong(S.liveGrid, S.stamp, S.s, x, z, b.pos.x, b.pos.z, cand);
  if (ep !== null && pre === undefined) shadowAlong(ep.grid, S.stamp, S.s, x, z, b.pos.x, b.pos.z, cand);
  let sum = 0;
  for (let ray = -1; ray <= 1; ray++) {
    const tx = b.pos.x + (px / pl) * off * ray, tz = b.pos.z + (pz / pl) * off * ray;
    const tgt = v3(tx, b.pos.y, tz);
    let hits = pre === undefined ? 0 : (pre >> ((ray + 1) * 2)) & 3;
    for (let k = 0; k < cand.length && hits < 3; k++) {
      const i = cand[k], o = i < S.nF ? ep.list[i] : S.live[i - S.nF];
      if (i < S.nF && S.fz[i] === 0) continue;
      if (o === b) continue;
      if (b.kind === "ice" && o.kind === "ice") continue;
      const t = segBoxHit(S.c, tgt, o);
      if (t > 0.03 && t < 0.97) hits++;
    }
    let occ = 1;
    for (let k = 0; k < hits; k++) { occ *= 0.35; if (occ < 0.09) { occ = 0.09; break; } }
    let above = pre !== undefined && ((pre >> (7 + ray)) & 1) === 1;
    if (pre === undefined) for (let k = 2; k <= 4; k++) {
      const t = k / 5;
      // chord test, mid-to-far samples with a fat margin: the burst's own ground and
      // rolling terrain never shade; a real rim or pit lip between the two does
      if (world.field.heightAt(x + (tx - x) * t, z + (tz - z) * t) > y + (b.pos.y - y) * t + 0.4) { above = true; break; }
    }
    if (above) occ *= 0.3;
    sum += occ;
  }
  return sum / 3;
}

// ------------------------------------------------------------- the aloft watch
// 0.6.11: while a davy round flies, the engine takes the still bodies as
// frozen (asleep or massless; never a man, never a mech's link — the game
// moves those by hand), files them on a shadow grid of the whole ground,
// flies a ghost of the round ahead on the wind the game layer lends it
// (world._windAt, world._windOn), and once the ghost has landed, precounts
// each frozen body's shadow hits against that burst point, a few bodies a
// step. At the burst the counts serve only if the round burst exactly where
// the ghost did, no frozen body woke, died or left, and the ground was not
// carved; otherwise the burst tests everything itself. Nothing here moves a
// body, draws from the rng, or writes anything a hash or a save reads; a
// step with no davy aloft pays one look at the projectile list.
const AL_FILE = 600, AL_GHOST = 60, AL_COUNT = 8, AL_STILL = { x: 0, z: 0 };
let AL_SERVED = 0; // bursts whose counts served (the suite reads it)
// the watch is taken over several steps: the bodies are read off a copy of
// the list a few hundred a step, and the ghost flies once the last is filed.
// The set is live from the first step, so a filed body that wakes before the
// filing is done counts against the watch like any later wake.
function aloftStart(world, p) {
  const set = new Set();
  FZ_SET = set;
  world._aloft = {
    p, spec: p.spec, scan: world.bodies.slice(), cursor: 0, list: [], set, grid: new Map(), alive: [], stamp: null, s: 0,
    woke: FZ_WOKE, edits: world.field.edits, ghost: null,
    landed: false, gone: false, bx: 0, by: 0, bz: 0, c: null, hits: new Map(), targets: null, next: 0,
  };
}
function aloftFile(world, ep) {
  const scan = ep.scan;
  for (let n = 0; n < AL_FILE && ep.cursor < scan.length; n++) {
    const b = scan[ep.cursor++];
    if (world.byId.get(b.id) !== b) continue; // gone since the copy was taken
    if (b.kind === "unit" || b.mechRef || b.kind === "mech" || b.kind === "mechlink" || b.kind === "mechfoot") continue;
    if (!(b.sleeping || b.invM === 0)) continue; // moving: the burst tests it live
    shadowFile(ep.grid, b, ep.list.length);
    ep.set.add(b); ep.list.push(b); ep.alive.push(b.alive ? 1 : 0);
  }
  if (ep.cursor >= scan.length) {
    const p = ep.p;
    ep.scan = null;
    ep.stamp = new Uint32Array(ep.list.length);
    ep.ghost = { x: p.pos.x, y: p.pos.y, z: p.pos.z, vx: p.v.x, vy: p.v.y, vz: p.v.z, life: p.life, t: world.t };
  }
}
// the ghost's flight: the round's own step (stepProjectiles), the frozen
// bodies standing in for the world, the wind read for each future step
function aloftFly(world, ep) {
  const g = ep.ghost, dt = world.dt, F = world.field, cand = _shCand;
  for (let n = 0; n < AL_GHOST && !ep.landed && !ep.gone; n++) {
    const w = world._windOn ? world._windAt(g.t) : AL_STILL;
    g.t += dt;
    g.life += dt;
    const p0x = g.x, p0y = g.y, p0z = g.z;
    g.vy -= world.gravity * dt;
    if (world.depotCombat && ep.spec.windF) {
      g.vx += (w.x - g.vx * 0.02) * ep.spec.windF * dt;
      g.vz += (w.z - g.vz * 0.02) * ep.spec.windF * dt;
    }
    g.x = g.x + g.vx * dt; g.y = g.y + g.vy * dt; g.z = g.z + g.vz * dt;
    let hitT = -1;
    const h1 = F.heightAt(g.x, g.z);
    if (g.y <= h1) {
      let a = 0, b = 1;
      for (let k = 0; k < 5; k++) {
        const m = (a + b) / 2;
        const mx = p0x + (g.x - p0x) * m, my = p0y + (g.y - p0y) * m, mz = p0z + (g.z - p0z) * m;
        if (my <= F.heightAt(mx, mz)) b = m; else a = m;
      }
      hitT = b;
    }
    let bestT = hitT < 0 ? 1.01 : hitT, hit = hitT >= 0;
    const p0 = v3(p0x, p0y, p0z), p1 = v3(g.x, g.y, g.z);
    cand.length = 0; ep.s++;
    shadowAlong(ep.grid, ep.stamp, ep.s, p0x, p0z, g.x, g.z, cand);
    for (let k = 0; k < cand.length; k++) {
      const b = ep.list[cand[k]];
      const isStruct = b.kind === "tower" || b.kind === "wall" || b.kind === "rock";
      if (b.invM === 0 && b.kind !== "chunk" && !isStruct) continue;
      if (isStruct && !b.alive) continue;
      const t = segBoxHit(p0, p1, b, null);
      if (t >= 0 && t < bestT) { bestT = t; hit = true; }
    }
    if (hit) { ep.landed = true; ep.bx = p0x + (g.x - p0x) * bestT; ep.by = p0y + (g.y - p0y) * bestT; ep.bz = p0z + (g.z - p0z) * bestT; ep.c = v3(ep.bx, ep.by, ep.bz); }
    else if (g.life > 8) ep.gone = true;
  }
}

function stepAloft(world) {
  const ep = world._aloft;
  if (!ep) {
    if (!world._windAt || world.projectiles.length === 0) return;

  else if (ep.targets === null || ep.next < ep.targets.length) aloftCount(world, ep);
}
