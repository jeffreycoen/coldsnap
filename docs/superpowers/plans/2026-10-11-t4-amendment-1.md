# T4 — Amendment 1: the door rule and the hold's clock

T4's dispatch stopped at the `depot-test` gate with five failures. Four are in era 49 (k), the sealed hold, which stamps a rider at 20 and checks him at 30 — it pinned the ten-second turn, and the plan's claim that only era 48 pinned the turn was wrong. One is the new era's own (d): a spooked person turned back to the door one step past it. The cause is `indoorsOf` in `people.js`: "nearer the inside spot than the door is long, and not on the outside spot" reads true again just outside the door, so the first leg re-arms and she oscillates. The rule becomes "nearer the inside spot than the outside one, and within the door's length of it". This amendment makes that one code change, licenses the one re-teach, and resumes the plan at its gates.

The tree holds T4's Steps 1–6 applied and uncommitted. This amendment inserts Step 6a before Step 7; the plan's other steps and numbers stand.

## Step 6a — the door rule, and the hold's clock

In `src/depot/people.js`, replace

```js
export function indoorsOf(u) {
  if (!u.pIn || !u.pOut) return false;
  const inD = Math.hypot(u.pIn.x - u.pos.x, u.pIn.z - u.pos.z), outD = Math.hypot(u.pOut.x - u.pos.x, u.pOut.z - u.pos.z);
  return inD < doorLen(u) && outD > 0.6;
}
```

with

```js
export function indoorsOf(u) {
  if (!u.pIn || !u.pOut) return false;
  const inD = Math.hypot(u.pIn.x - u.pos.x, u.pIn.z - u.pos.z), outD = Math.hypot(u.pOut.x - u.pos.x, u.pOut.z - u.pos.z);
  return inD < doorLen(u) && inD < outD; // nearer the inside spot than the outside one — one step past the door is out
}
```

The comment above the function (`// indoorsOf: is she in the house? ...`) reads the same in spirit and is left as it is.

Re-teach, licensed (the turn is thirty seconds): in `scripts/tests/49-the-people.mjs` line 134, replace

```js
    a.sickAt = 20;
```

with

```js
    a.sickAt = 0; // 0.6.4: thirty seconds to the turn — stamped at 0, checked at 30
```

Old → new: `a.sickAt = 20` → `a.sickAt = 0`. The asserted content — a bitten rider turns inside the hold when his time is up and bites the rider with him — is unchanged; only the stamp moves so the check at `w.t = 30` falls at the turn.
